# Canadian Charter of Rights and Freedoms in Akoma Ntoso

The Canadian Charter of Rights and Freedoms, sections 1 to 34 of the Constitution Act, 1982, in English and French, in Akoma Ntoso XML, with a CSS stylesheet. It was generated by Claude for Grant Vergottini.

**This is not an official version.** For the official text, see Justice Canada.

## Files

| File | Purpose |
| --- | --- |
| `canadian-charter-of-rights-and-freedoms.xml` | The Akoma Ntoso document, with both languages |
| `canadian-charter-of-rights-and-freedoms.css` | The stylesheet, linked from the XML |
| `view.html` | A page that shows one language at a time |
| `index.html` | Landing page for GitHub Pages |

To view the document locally, keep the XML and CSS files in the same folder and open the XML in a browser.

## About the markup

- **Standard:** Akoma Ntoso 2.0 (AKN 3.1). The namespace is `http://docs.oasis-open.org/legaldocml/ns/akn/3.0`, with `version="3.1"` on the root element.
- **Validation:** The XML validates against the Akoma Ntoso 2.0 cs01 schema.
- **Structure:** A `<documentCollection>` holds one `<act>` per language in a `<component>`. Each has the opening recital, then a `<part>` with `<division>` (the unnumbered subheadings), `<section>`, `<subsection>`, `<list>` and `<point>` elements.
- **Marginal notes:** These are `<heading>` elements on the section or subsection they label.
- **`intro` and `content`:** Text followed by a list is in `<intro>`. Other text is in `<content>`. The closing words of subsection 23(1) are in `<wrapUp>`.
- **Cross-references:** References to sections and subsections of the Charter are `<ref>` elements.
- **Identifiers:** Every element with an `eId` also has a `GUID`. Text-level `<p>` elements have neither. The two languages share the same structure, so the `eId`s differ only in their `cmp_eng` or `cmp_fra` prefix.

## Status of the text

Both language versions are equally authoritative, so neither is marked as a translation of the other.

The text is the current consolidation, not the Charter as proclaimed on April 17, 1982. It includes two later changes:

| Where | Change |
| --- | --- |
| Paragraph 25(b) | Changed by the Constitution Amendment Proclamation, 1983 |
| Section 16.1 | Added by the Constitution Amendment, 1993 (New Brunswick), proclaimed March 12, 1993 |

The expression date in the metadata is March 12, 1993, the date of the later change.

## Left as they are

Both texts are unchanged. A check of every word against the source shows no differences. These are a few things that may look odd:

| Where | As printed | Note |
| --- | --- | --- |
| Section 30, paragraph 32(1)(a) | The Yukon Territory and the Northwest Territories | Nunavut did not exist in 1982 and is not named |
| Subsections 33(3) and 33(5) | Both have the marginal note "Five year limitation" | |
| French lists | `a)`, `b)` | The English has `(a)`, `(b)` |

Justice Canada's end note marks are left out, because they are editorial and not part of the Charter. Part II, section 35 and the rest of the Constitution Act, 1982 are not included.
